# User Story

As a user, I want to log in with a valid username and password and recover my password through the same client-side validation rules, so I can interact with the static interface without a server or backend.

## Acceptance criteria
- The login page shows clear fields and feedback.
- Invalid username and password values must show accessible errors.
- Successful validation displays a success status region without exposing the password value.
- Forgot Password toggles to a recovery view and validates the username.
